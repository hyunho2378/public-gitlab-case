# 현재 구성 (2026. 11. 26. 공공기관 누리집 사업 소개 형식)

공공 깃랩 사례를 가상의 기관 누리집(AI 정부 실험실)에서 사업을 소개하는 형식으로 구성. KRDS 공식 CSS와 마크업(공식 배너 자리, 헤더, 메인 메뉴, 브레드크럼, 사이드 메뉴, 탭, 단계 표시기, 표, 아코디언, 배지, 푸터)을 `src/krds`에 두고 그대로 씀.
쪽: 메인, 사업 소개(추진 배경, 주요 기능, 이용 방법, 추진 성과), 자료실, 알림마당. 주소는 해시(#/intro/background 등).
공식 누리집 문구와 정부 인증 표시는 쓰지 않고 공식 배너 자리에 가상의 누리집 안내를 적음. 장식용 스크롤 연출과 자동 재생은 없음.
아래 표는 이전 구성 기록이다.

- `npm run build` 통과(압축 끔, 샌드박스에 lightningcss 네이티브 바인딩 없음)
- 320, 390, 768, 1024, 1440, 1920, 2560 폭에서 가로 넘침 0(scrollWidth와 clientWidth 같음), 화면 밖으로 나간 글 0

- 본문 글자 17px과 행간 28.39px, 캡션과 출처 14px을 getComputedStyle로 측정(1440과 390 모두)
